Les nominations pour les Game Awards 2021

Par Cédric Fischer
18 novembre 2021
0 Partage

Comme chaque fin d’année, l’industrie organise les Game Awards pour célébrer les meilleurs jeux de l’année, dans différentes catégories. Le tout organisé par Geoff Keighley, qui en profite pour nous rappeler que c’est pas loin d’une cinquantaine de jeux qui vont être annoncés durant l’événement.

Crédit images : Game Awards

La petite tape dans le dos

L’édition 2021 des Game Awards se déroulera à Los Angeles le 9 décembre prochain, à 16h (heure de l’Est). Comme bien souvent, les six jeux essayant de prendre la place du « Jeu de l’année » ont des nominations dans plusieurs catégories.

Ainsi, le Deathloop d’Arcane Studios trouve sa place dans neuf nominations, avec la meilleure réalisation ou la meilleure narration. De son côté, l’excellent It Takes Two est dans cinq catégories, comme c’est le cas aussi pour Psychonauts 2 qui est développé par Double Fine Studios. Marvel’s Guardians of the Galaxy, produit au Québec par Eidos Montréal récolte 4 nomnimations, dont meilleur jeu d’action et d’aventure.

Vous pouvez d’ailleurs allez voter pour les gagnants sur le site de The Game Awards.
